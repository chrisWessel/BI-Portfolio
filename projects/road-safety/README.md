# Road safety dashboard

An Excel dashboard for exploring casualty severity and road-incident patterns.

![Road safety dashboard](../../assets/previews/road-safety.png)

## Questions explored

- How do fatal, serious, and slight casualties compare?
- How do casualties vary by vehicle, road type, area, and light conditions?
- How does the monthly pattern change across selected years?

## Tools

Microsoft Excel · Interactive filters · Data modelling

## Portfolio notes

The preview shows a severity overview, monthly comparison, and breakdowns by vehicle and road context. The workbook and source data are not included in this public repository.
